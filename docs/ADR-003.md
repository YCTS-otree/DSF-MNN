# ADR-003：独立 Cognitive Dreaming、ACR 与原生 CompactionEngine

日期：2026-10-24。状态：隔离真实会话实验已验证；正式 DSF 未启用。

## 决策

使用 Python 模块化单体执行分段语义提取、证据验证、CPU 索引和记忆巩固；通过单次 Node 子进程调用已有远程 Provider。不依赖停摆的 DSH Agent，不部署 Python 网络服务，不使用 GPU。保留 v1.0.0 的离线算法与接口作为对照。

ACR 产出可审查、可拒绝的 Context Plan。长期记忆先持久化，计划绑定原始事件、活动 surface、节点版本和 Goal State；本地词表计数与原生 Provider 完整请求计数分别记录。只有后者确认预算后，才允许隔离 DSH 提交。

新增 `cognitiveEngineClass()`，直接继承本机 `@deepseek-ai/dsh-compaction` 的公开 `CompactionEngine`。该类注册 `ctx.compaction`，不加载或调用 Basic。旧的 Basic `summarize()` 扩展工厂继续保留用于历史测试。

## 为什么仅覆盖 summarize 不够

本机 DSH 0.2.0-rc.2 的 Basic 已决定压缩选区、近期尾部和摘要调用，传给 summarize 的输入不能完整表达 MNN 对旧事件的选择、双重 Carryover/长期保存、有效系统投影与显式来源范围。为了首次恢复，降低为固定旧历史摘要会损失这些要求。

新后端保留 DSH Session、事件追加、surface replacement、`compactCheckpointSource`、配对检查、`runMaintenance`、持久化 write lease 和 flush。使用标准 start/summary/checkpoint/end 事件顺序，summary 与 checkpoint 连续追加。失败记录 end/error 并上抛，不静默降级。

原生 Session 只允许在打开的 Agent step 内写 system/message。因此维护阶段保留原始 system anchor 和最新完整 system，替换中间区间；后续原生 AgentLoop 在正常 step 内规范系统投影。实测提交后 5 个 surface 节点，原始事件继续完整保留。禁止用普通用户记忆冒充 Core/Self。

## 一致性和恢复

MNN 与 DSH 没有跨数据库原子事务。记忆先提交、版本再验证、DSH 后提交；崩溃时核对已保存的 Context Plan、compaction ID、来源 seq 与原生日志。原始 Session 备份始终保留。语义任务使用数据库路径级 OS 文件锁，进程退出释放；每段事务、收据和水位支持恢复，配置或源码变化拒绝复用同一 run。

计划生成与提交之间的 live 并发故障矩阵、自动压力/overflow 全链路和生产 Cordis 配置尚需专项验证。本次实验只在静止的隔离副本运行，不把它解释为生产并发正确性证明。

## 代价与保留项

CPU 词项哈希仍是检索基线；远程 LLM 提供真实语义提取，不使哈希向量变成神经语义向量。原始证据回查与三种回忆共用相同 SQLite。没有重写 Self Model、扩大工具权限、开启互联网，也没有修改官方 node_modules。

正式启用需新的 DSF 完整备份门禁和显式配置审查。失败回到已验证的原始恢复点或停止；本轮不得自动启动 Basic。
