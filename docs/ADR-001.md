# ADR-001：Python 内存储核心与进程内 DSH 适配边界

日期：2026-10-24。状态：采纳（独立研发范围）；生产启用另行验收。

## 事实与选择

实际工作区 `DSF_MNN` 已有空 Git 仓库，无 remote；相邻 `DS_Friend` 是独立且有未提交修改的仓库。因此直接使用用户指定工作区，不创建嵌套仓库，不移动主项目。分支 `codex/mnn-foundation`。

现有 Python 3.10.11、SQLite 3.40.1（FTS5）、Node 24.19.0、npm 11.17.0 可用；numpy、pytest 已有。全局 tsc、hnswlib、sentence-transformers 未安装。不新增环境或下载模型。

选 B 的轻量变体：Python 模块化单体 + JavaScript ESM DSH 边界适配器。稳定 JSON 协议允许未来 TypeScript 客户端；当前无需引入 TS 编译工具链。Python 核心可嵌入或通过短生命周期 stdio 子进程调用，无常驻 HTTP 服务、无独立数据库服务器。跨存储用稳定 ID、摘要和 prepared 收据协调，不能声称分布式原子事务。

SQLite WAL + FULL 同步保存事实、来源、关系、版本、任务收据与向量。初版精确余弦用于正确性基线；不预装 HNSW。实测 100/1k/10k 后再决定 ANN。FTS5 输入显式中英文词项与汉字二元组，避免默认 unicode61 将连续中文看作整词。

默认 HashEmbedding 仅为确定性词项基线，不能代表真实语义模型。可替换 Provider 与本地 SentenceTransformer Provider 分离；后者只接受本地路径且禁止自动下载。向量空间按模型、版本、维度、归一化和索引版本标识，切换必须显式重建。

## DSH 决策

实际安装 `@deepseek-ai/dsh* 0.2.0-rc.2`。继承 BasicCompactionEngine，仅覆盖 summarize；不重写 compactRegion/compactNow/自动压力与 overflow。官方仍管理 start/summary/end、surface replacement、持久 flush、维护锁、取消和 Token Meter 收敛验证。

summarize 的公开参数不含准确 sourceEventSeqs。禁止按文本模糊匹配或把整个 log 当作选区。后端必须由调用方提供经过验证的精确快照解析器；未完成运行版本选区绑定前，生产后端不可启用。影子计划可独立验证，不冒称端到端接入完成。

P0/P1 均在同一真实 system role 内按现有 prompt section 排序；order 不是独立权限等级。记忆仅通过上下文数据接口返回，不注册为 system 规则。保留主项目现有 Core/Self v0.1.0，不复制身份正文到新数据库，不重写起源信件。

## 代价与后续

双语言有协议与取消维护成本；换取研究算法可测试和 DSH 可靠性复用。初版无自动 LLM 提取，使用有来源类型的结构化输入及确定性 Episode 归并；自动语义边界和神经检索质量待后续模型验收。上线必须遵守主项目停服和完整校验 .DSF 的集中门禁；本轮不触发任何生产功能开关。
